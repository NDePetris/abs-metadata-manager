# Design

Practical native Streamlit desktop workspace. Retain the configured light theme; no custom CSS, animation, branding assets, or mobile-specific UI.

The sidebar holds Library, five navigation choices, and connection status. Normal pages resolve the latest completed inventory internally. Historical snapshots are Advanced history tools.

Match & Verify centers the selected book and Previous/Next controls. Search reference sources is collapsed until needed. Each field aligns a wrapping saved value with a typed desired editor; evidence and references disclose underneath. Explicit field, selected-field, and all-displayed-field confirmation share one form. Covers, chapters, and source integrity remain separate read-only details. Use text labels for acceptance, evidence assessment, and pending corrections.

Changes groups confirmed targets and legacy human proposals by book. Selection, field write approval, exact preview, phrase, and acknowledgement precede guarded execution. Calibre validation is separate and read-only. History emphasizes chronological activity; journals and rollback are advanced controls, expanded when recovery is required.

Desktop acceptance sizes: 1024×800 and 1280×800. Prefer readable saved/desired values over a crowded five-column table. Long scalar text wraps; structured series editing retains decimal strings and multiple rows. Missing file inspection displays Not checked and does not create a correction.
